# 艾澤拉斯掛機錄

以《魔獸世界》世界觀為題材的單人網頁掛機 RPG，玩法參考網頁掛機遊戲「上漲谷」。整個遊戲是一個 `index.html`，不需要建置或伺服器。

## 遊玩
- 直接用瀏覽器開啟 `index.html`，或開啟 GitHub Pages：Settings → Pages → Branch 選 `main`、資料夾 `/ (root)`。
- 存檔存在瀏覽器的 localStorage；換裝置可在「設定」頁複製存檔碼再匯入。

## 系統
- 聯盟／部落兩陣營、8 個種族（依經典版的種族職業限制）、8 個職業，技能與天賦使用經典版名稱
- 精緻像素風角色：種族外型、依護甲類型變化的肩甲與頭盔、陣營披風、武器稀有度光暈、粒子技能特效
- 10 個地區（1–60 級），一般、精英、稀有怪物，自動戰鬥與 2D 橫向戰鬥畫面
- 六種稀有度裝備、附魔卷軸強化（100% / 60% / 10%，消耗附魔次數）
- 職業套裝：黑石深淵掉落地城一套裝、熔火之心掉落 T1 套裝，2／4／5 件套裝效果
- 5 個聲望陣營與聲望商人、地區任務線與每日清剿
- 5 個五人地城與 1 個 20 人團隊副本，首領有激怒計時
- 獵人寵物、術士小鬼與虛空行者
- 休息經驗（離線累積，經驗條藍色段顯示）
- 快捷列（冷卻轉圈、點擊切換自動施放）、玩家與目標頭像框（精英金龍框）
- 經典格式物品提示：綁定、護甲類型、武器傷害與速度、耐力與主屬性、需要等級；像素物品圖示
- 職業訓練師（花錢學新技能）、40 級騎術坐騎、聲望史詩坐騎
- 地城小怪群、隊友血條、首領 60%／30% 全隊技能、需求擲骰分裝
- 離線掛機收益（最多 12 小時）
